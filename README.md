# UEBA

Программный макет системы обнаружения аномальной активности пользователя на основе модели AutoEncoder.

## Возможности

- сбор данных о пользовательской активности и состоянии системы;
- формирование обучающей выборки;
- обучение модели нормального поведения;
- обнаружение аномальной активности в режиме реального времени;
- сохранение и повторное использование обученной модели;
- журналирование обнаруженных аномалий.

## Собираемые признаки

Во время работы программа собирает следующие характеристики:

- количество кликов мышью;
- расстояние, пройденное курсором;
- количество нажатий клавиш;
- количество прокруток колесика мыши;
- общий объем прокрутки;
- количество новых процессов;
- объем входящего сетевого трафика;
- объем исходящего сетевого трафика;
- загрузка процессора;
- использование оперативной памяти;
- время бездействия пользователя (используется только при обучении).

## Установка

Требуется **Python 3.11** или новее.

Создание виртуального окружения:

```bash
python -m venv .venv
```

Активация окружения.

Windows:

```bash
.venv\Scripts\activate
```

Linux/macOS:

```bash
source .venv/bin/activate
```

Установка зависимостей:

```bash
pip install -r requirements.txt
```

## Использование

### Автоматический режим

```bash
python main.py
```

При запуске без аргументов программа автоматически:

1. собирает обучающие данные;
2. обучает модель;
3. запускает обнаружение аномальной активности.

### Доступные команды

| Команда                      | Описание                     |
|------------------------------|------------------------------|
| `python main.py --collect`   | Сбор обучающей выборки       |
| `python main.py --train`     | Обучение и сохранение модели |
| `python main.py --detect`    | Запуск обнаружения аномалий  |
| `python main.py --show-logs` | Просмотр журнала аномалий    |
| `python main.py --help`      | Вывод справки                |

## Принцип работы

1. Программа собирает информацию о действиях пользователя и состоянии системы.
2. Собранные данные нормализуются.
3. AutoEncoder обучается восстанавливать нормальное поведение пользователя.
4. На основе ошибки реконструкции определяется порог аномальности.
5. Во время мониторинга вычисляется ошибка реконструкции новых наблюдений.
6. При превышении порога событие считается аномальным и сохраняется в журнал.
